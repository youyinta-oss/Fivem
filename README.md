# FiveM 赠礼系统插件

## 功能介绍

### 赠礼功能
- 给指定玩家赠送物品、货币、武器、车辆
- 给全部在线玩家赠送礼物
- 支持留言功能

### 红包功能
- 给全部在线玩家发送红包
- 支持多种红包类型：物品、货币、武器、车辆
- 三种分配模式：
  - 随机分配：金额随机分给抢到的玩家
  - 平均分配：金额平均分给抢到的玩家
  - 先到先得：前N个玩家抢到全额
- 可设置过期时间

### 界面
- 用户界面：玩家可以发送礼物、抢红包、查看历史记录
- 管理界面：管理员可以查看所有记录、发送礼物和红包

## 依赖
- ESX 框架
- oxmysql

## 安装
1. 将资源文件夹放入 resources 目录
2. 在 server.cfg 中添加 `ensure gift_system`
3. 导入数据库表（插件会自动创建）
4. 重启服务器

## 命令
- `/gift` - 打开用户界面
- `/giftadmin` - 打开管理界面（需要管理员权限）

## 配置
在 `config.lua` 中可以配置：
- 数据库表前缀
- 武器列表
- 车辆列表
- 红包最大玩家数
- 红包超时时间
